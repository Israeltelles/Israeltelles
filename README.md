## Sobre mim

Sou estudante de Análise e Desenvolvimento de Sistemas, interessado em compreender como a tecnologia pode ser utilizada para resolver problemas e transformar dados em conhecimento.

Atualmente, concentro meus estudos principalmente em:

-  Análise e Ciência de Dados.
-  Inteligência Artificial e Machine Learning.
-  Programação com Python.
-  Banco de Dados e processos ETL.
-  Desenvolvimento de Software.

Busco minha primeira oportunidade profissional na área de Tecnologia da Informação, com interesse especial em Dados e Desenvolvimento.

## Portfólio

Projetos desenvolvidos durante meus estudos e experiências práticas.

### 📊 Análise e Ciência de Dados

**[Ibovespa — Análise e Previsão de Ações](https://github.com/Israeltelles/ibovespa-ml-analysis)**

Projeto de análise de dados históricos do mercado financeiro, envolvendo exploração de dados, preparação de informações e experimentos com Machine Learning.

### 💻 Desenvolvimento Web

**[Sistema de Gestão de Eventos](https://github.com/Israeltelles/SistemaEventos)**

Aplicação acadêmica desenvolvida com C# e ASP.NET Core MVC, utilizando Entity Framework e SQL Server. O sistema permite o gerenciamento de eventos, inscrições, confirmação de presença e emissão de certificados.

### 🧬 Bioinformática

**[Mutation Hunter](https://github.com/Israeltelles/Mutation-Hunter)**

Projeto voltado ao estudo de variantes genéticas humanas, relacionando conhecimentos de programação, análise de dados e bioinformática.
